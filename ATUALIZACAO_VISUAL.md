# Atualização visual — Presença & Aula

A tela inicial foi reorganizada com cabeçalho azul, indicadores e cartões coloridos inspirados na referência enviada. Os cartões se adaptam à largura da tela e levam às funcionalidades existentes: chamada, turmas/alunos, planos de aula e histórico.

## Executar na Web

1. Copie `.env.example` para `.env` e preencha a URL e a Publishable Key do seu projeto Supabase.
2. Execute `npm install`.
3. Execute `npx expo start --web`.

Não compartilhe o arquivo `.env` com credenciais reais.
